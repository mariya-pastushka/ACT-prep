# ACT space — дизайн проекта

Сохранять для следующих страниц: тёплый молочный фон #fcfaf7, основной текст #30253d, пастельный фиолетовый #e8dcf3, лавандовый #aa81c3, мягкий жёлтый #f4db85 только для кнопок и небольших деталей. Воздушная журнальная сетка, крупная выразительная типографика, тонкие линии, умеренные скругления. Без фотографий и сгенерированных людей. Тематические системные эмодзи; Apple Color Emoji на устройствах Apple, системный аналог на остальных. Четыре смысловых блока: приветствие, формат, баллы, первый шаг. Автор: Диас Муратов, https://t.me/disamura. Адаптивная мобильная версия обязательна. Стек: React + Next.js, статический экспорт. Актуальные сведения проверять по act.org, ссылки оставлять в интерфейсе.
