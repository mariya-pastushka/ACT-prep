# ACT space

Приветственная страница подготовки к ACT. React + Next.js. Автор: Диас Муратов (@disamura).

## Запуск

Откройте терминал в этой папке:

```sh
npm install
npm run dev
```

Адрес: http://127.0.0.1:3000

## Сборка

```sh
npm run build
```

Статический сайт будет в `out/`. Стиль для следующих страниц описан в DESIGN.md.

Системные эмодзи отображаются в стиле Apple на устройствах Apple. На Windows используется Segoe UI Emoji. Шрифт Golos Text загружается из Google Fonts; без сети доступен Arial.
